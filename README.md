# HalmstadLokaler

This purpose of this application is to provide a marketplace for office spaces in Halmstad. It's built using a MERN stack. It's all built in TypeScript.

Technologies
* MongoDB
* Express.JS
* React.JS
* NodeJS
* AWS S3 (Image storage)
* Resend (Email relay)
* Loopia (Domain)
* Loopia (DNS)
